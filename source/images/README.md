# Theme Images

The images in this directory are **examples**. Replace them with your own:

- `avatar.jpg` — Your avatar (recommended: 200×200px, 1:1 ratio)
- `bg-default.png` — Default background image (recommended: 1920×1080px, landscape)
- `favicon.png` — Site favicon (recommended: 32×32px or 64×64px)

You can also add more background images and reference them in `_config.yml`:

```yaml
backgrounds:
  - /images/bg-default.png
  - /images/bg-02.jpg
  - /images/bg-03.jpg
```

The `icons.svg` file contains the Material Symbols icon sprite used by the theme — don't delete it.
