# Theme Images

Place the following images in this directory:

- `avatar.jpg` — Your avatar (recommended: 200x200px, 1:1 ratio)
- `bg-default.jpg` — Default background image (recommended: 1920x1080px, landscape)
- `favicon.png` — Site favicon (recommended: 32x32px or 64x64px)

You can also add more background images and reference them in the theme's `_config.yml`:

```yaml
backgrounds:
  - /images/bg-default.jpg
  - /images/bg-02.jpg
  - /images/bg-03.jpg
```
